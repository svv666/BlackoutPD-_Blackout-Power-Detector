# Power Guard

**Power Guard** — небольшая программа для Windows, которая защищает ноутбук при пропадании электричества.

Если свет отключился, ноутбук продолжает работать от батареи. Power Guard замечает это и запускает обратный отсчёт. 

Если электричество вернулось — ничего не происходит. Если нет — компьютер корректно выключается, и вы не теряете данные из-за внезапного разряда батареи.

Готовый файл **`PowerGuard.exe`** запускается двойным щелчком. Устанавливать Python не нужно.

- **Версия:** 1.0.0
- **Платформа:** Windows 10 / 11
- **Язык:** русский
- **Лицензия:** GNU GPL v3.0

## Возможности


- Проверяет питание каждую секунду.
- При переходе на батарею запускает отсчёт (по умолчанию 60 секунд).
- Отменяет выключение, если свет вернулся.
- Выключает компьютер, если питание так и не появилось.
- Показывает состояние питания и заряд батареи.
- Работает в системном трее — окно можно свернуть.
- Может запускаться вместе с Windows.
- Запоминает настройки между запусками.
- Не даёт открыть две копии программы одновременно.

## Как пользоваться

1. Запустите `PowerGuard.exe`.
2. Нажмите **ВКЛ** — кнопка станет зелёной, защита работает.
3. При желании включите **Автозапуск с Windows**.
4. Сверните окно — программа продолжит работать в трее.

> Важно: если закрыть окно крестиком во время отсчёта, программа продолжит работать
> в трее и выключит компьютер. Чтобы точно отменить выключение — нажмите красную
> кнопку «Остановить и закрыть».

## Важно знать

- Программа рассчитана на ноутбук с батареей.
- Права администратора обычно не нужны.
- Файл не подписан, поэтому SmartScreen может показать предупреждение при первом запуске — это нормально.
- Программа не отправляет данные в интернет.

## Дисклеймер

Power Guard выключает компьютер при определённых условиях. Перед использованием
проверьте работу в режиме `--dry-run` и выберите задержку осознанно.
