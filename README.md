# BlackoutPD-_Blackout-Power-Detector
Power Guard — простая утилита для Windows: следит за питанием ноутбука, при пропадании света запускает отсчёт и корректно выключает компьютер, если питание не вернулось. Защищает данные от внезапного отключения, работает в трее, умеет запускаться с Windows, позволяет выбрать задержку и не требует установки Python. Есть автозапуск, защита от дублей.
